# Movie Query and Recommendation System

This repository contains all the code files required to implement the Movie Query and Recommendation System. The system includes functionalities such as user login, customized movie search, and personalized movie recommendations generated using an SVD-based collaborative filtering approach.

## Pre-trained SVD Model

To support the recommendation functionality, a pre-trained SVD model is provided, which significantly reduces the setup time and improves the ease of deployment. You can download the pre-trained SVD model from the following Google Drive link:
